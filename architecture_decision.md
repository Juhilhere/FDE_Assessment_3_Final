# Architecture Decision Memo

Ship the single-agent baseline for the MVP. The same six public cases passed all minimum evaluator checks for both architectures in local testing, with zero LLM calls. Single keeps one orchestration path; staged separates evidence collection and adjudication but adds no quality benefit on this test set. Both route outage, missing data, overlap, budget, sensitive access, and prompt-injection cases to human review. Staged is retained as a future seam, but it adds coordination complexity now. The synthetic dataset and mock API require production validation for authenticated vendor APIs, policy versioning, audit retention, privacy/legal processing, identity controls, adversarial text, and broader hidden cases. The problem is primarily evidence retrieval and policy application, so deterministic gates are a stronger MVP foundation than unnecessary orchestration.
